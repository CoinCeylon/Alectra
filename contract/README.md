# Alectra Governance Contract

This directory contains the Aiken smart contract for the Alectra governance system and deployment scripts.

## Structure

```
contract/
├── validators/          # Aiken smart contract source code
│   └── governance.ak   # Main governance contract
├── scripts/            # Deployment and utility scripts
│   └── deploy.ts      # Contract deployment script
├── plutus.json        # Compiled contract (generated by aiken build)
├── aiken.toml         # Aiken project configuration
└── package.json       # Node.js dependencies for scripts
```

## Prerequisites

1. **Aiken** - Install from [aiken-lang.org](https://aiken-lang.org/)
2. **Node.js** - For running deployment scripts
3. **Blockfrost API Key** - Get from [blockfrost.io](https://blockfrost.io/)

## Quick Start

### 1. Install Dependencies

```bash
cd contract
npm install
```

### 2. Build the Contract

```bash
npm run build
# or directly: aiken build
```

This generates `plutus.json` with the compiled contract.

### 3. Configure Environment

```bash
cp .env.example .env
# Edit .env with your Blockfrost API key and settings
```

### 4. Deploy Contract (Simulation)

```bash
npm run deploy
```

This runs a simulation and shows what would be deployed without actually submitting to the blockchain.

### 5. Deploy Contract (Real)

```bash
npm run deploy:real
```

**Note:** Real deployment requires wallet connection implementation (see Deployment section).

## Deployment

The deployment script creates the initial governance UTxO with:

- **Initial Treasury**: 1000 ADA (configurable)
- **Governance Rules**: Voting periods, quorum requirements, etc.
- **Admin Controls**: For managing the governance system

## Building

```sh
aiken build
```

## Configuring

**aiken.toml**

```toml
[config.default]
network_id = 41
```

Or, alternatively, write conditional environment modules under `env`.

## Testing

You can write tests in any module using the `test` keyword. For example:

```aiken
use config

test foo() {
  config.network_id + 1 == 42
}
```

To run all tests, simply do:

```sh
aiken check
```

To run only tests matching the string `foo`, do:

```sh
aiken check -m foo
```

Use:
